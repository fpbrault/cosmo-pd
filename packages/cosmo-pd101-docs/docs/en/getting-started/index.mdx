# Getting Started

Welcome to the **Cosmo PD-101** -- a phase distortion synthesizer inspired by the legendary Casio CZ-101, extended with modern synthesis capabilities and available as a web app and DAW plugin.

## What You Need

- A computer (Windows, macOS, or Linux)
- A web browser (Chrome, Firefox, Edge -- latest versions)
- A MIDI keyboard or controller (optional but recommended)

## First Sound

<Steps>

### Open the Web App

Navigate to [cosmo.purraudio.dev](https://cosmo.purraudio.dev) in your browser. No installation required.

### Play a Note

Press keys on your computer keyboard (**A S D F G H J K** for a C major scale) or connect a MIDI controller.

### Adjust to Taste

Browse the preset library and select a sound you like. Tweak individual parameters to understand what each one does.

</Steps>

:::tip
Start with the preset browser to explore factory sounds before diving into synthesis.
:::

## The Interface at a Glance

Use the **Simple / Advanced** switch at the top of the synth. New sessions start in **Simple**; your workspace choice is remembered. Both workspaces edit the same sound, so switching keeps your current patch.

### Simple: play and shape a sound

Four **Macros** stay available beside three sections. Select a collapsed section to expand it:

| Section | What to do |
|---------|------------|
| **Sound** | Choose algorithms for each line, adjust DCA (level), DCW (waveshape), octave and blend, then set line routing, ring/noise modulation, detune, mono and portamento. Blend appears when algorithm B is enabled. |
| **Envelope** | Select line 1 or 2. Choose presets for DCO (pitch), DCW (waveshape), and DCA (amplitude), or click an envelope graph to open its editor. |
| **Effects** | Add effects to the six slots and open an effect to edit its settings. |

The line 1 octave control transposes both lines. The line 2 octave control sets an offset relative to that base octave.

### Advanced: edit the full patch

Switch to **Advanced** for the full line editors, modulation matrix, and global tempo/voice allocation controls. The synth UI is organized into sections:

| Section | What It Controls |
|---------|-----------------|
| **Phase Lines** | Two oscillator lines -- each with its own algorithm, envelope, and pitch settings, and blending with a secondary |
| **Envelope Editor** | 8-step step-function envelopes for DCO(pitch), DCW(waveshape), and DCA(amplitude), per line |
| **Modulation Matrix** | Route 11 modulation sources to most synth params, with adjustable depth |
| **FX Chain** | 6 serial effect slots with 17 effect types |
| **Global Controls** | Polyphony, portamento, volume, pitch bend range, velocity sensitivity |

## Connecting a MIDI Controller

1. Open the browser's **MIDI settings**.
2. Allow access to your MIDI device when prompted.
3. Select your controller from the MIDI input dropdown.
4. Play.

## Mini Keyboard

An on-screen keyboard is available when no physical MIDI controller is connected.

- **Click or drag** across keys to play.
- **Octave shift** buttons move the range up/down.
- In **Velocity** input mode, press near the top of a key for a stronger note and near the bottom for a softer note.
- In **Aftertouch** input mode, drag upward after pressing to add pressure. Choose the input mode in keyboard settings.
- Works in both the web app and the plugin UI.

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| A S D F G H J K | Play notes (C major scale: C4-C5) |
| Space | Toggle sustain pedal |
