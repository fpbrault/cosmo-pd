# Algorithmes

<img src="../../assets/AlgoSelect.jpeg" />

15 algorithmes de distorsion de phase : 1 algorithme CZ-101 legacy + 14 algorithmes originaux Cosmo.

:::info
Les algorithmes CZ-101 legacy sont fournis pour la compatibilité avec les imports SysEx Casio CZ-101. Les algorithmes originaux Cosmo étendent considérablement les capacités du matériel d'origine.
:::

## CZ-101 Legacy

- **CZ Saw** <Badge text="Legacy" type="tip" /> -- Dent de scie brillante classique. Options Forme d'onde 1/2, Fenêtre.
- **CZ Square** <Badge text="Legacy" type="tip" /> -- Onde carrée, creuse et nasillarde.
- **CZ Pulse** <Badge text="Legacy" type="tip" /> -- Plus étroite que dent de scie, bourdonnante. Sons de cuivres.
- **CZ Double Sine** <Badge text="Legacy" type="tip" /> -- Douce, arrondie. Deux composantes sinusoïdales.
- **CZ Saw Pulse** <Badge text="Legacy" type="tip" /> -- Brillance de dent de scie avec caractère de largeur d'impulsion.
- **CZ Reso 1-3** <Badge text="Legacy" type="tip" /> -- Tons métalliques résonants avec fonction de fenêtre.

## Algorithmes originaux Cosmo

### Bend <Badge text="Nouveau" type="info" />
Paramètres : Courbe Bend, Biais Bend, Genou Bend. Changement timbral lié à la hauteur, tons vocaux expressifs.

### Sync <Badge text="Nouveau" type="info" />
Paramètres : Ratio Sync, Phase Sync, Courbe Sync, Fenêtre Sync. Style hard-sync, leads métalliques perçants.

### Pinch <Badge text="Nouveau" type="info" />
Paramètres : Focus Pinch, Asym Pinch, Courbe Pinch, Drive Pinch. Tons nasillards serrés à distorsion agressive.

### Fold <Badge text="Nouveau" type="info" />
Paramètres : Étages Fold, Inclinaison Fold, Symétrie Fold, Douceur Fold. Plieur d'onde -- subtil à chaotique.

### Skew <Badge text="Nouveau" type="info" />
Paramètres : Biais Skew, Courbe Skew, Étendue Skew, Inclinaison Skew. Formes d'onde asymétriques, nappes évolutives.

### Twist <Badge text="Nouveau" type="info" />
Paramètres : Harmoniques Twist, Profondeur Twist, Phase Twist, Forme Twist. Timbres tourbillonnants en spirale.

### Clip <Badge text="Nouveau" type="info" />
Paramètres : Drive Clip, Forme Clip, Biais Clip, Douceur Clip. Saturation chaude à clipping numérique dur.

### Ripple <Badge text="Nouveau" type="info" />
Paramètres : Fréq Ripple, Profondeur Ripple, Phase Ripple, Forme Ripple. Textures aquatiques ondulantes.

### Mirror <Badge text="Nouveau" type="info" />
Paramètres : Centre Mirror, Mélange Mirror, Clip Mirror, Skew Mirror. Sons de cloches métalliques.

### FOF (Formant) <Badge text="Nouveau" type="info" />
Paramètres : Ratio FOF, Resser FOF, Offs FOF, Skew FOF. Timbres vocaux/formantiques.

### Terrain <Badge text="Nouveau" type="info" />
Paramètres : Ratio Terrain, Prof Terrain, Phase FM Terrain, Forme Terrain. Timbres organiques inspirés du paysage.

### Stutter <Badge text="Nouveau" type="info" />
Paramètres : Segs Stutter, Invers Stutter, Gliss Stutter, Espace Stutter. Textures granuleuses de bégaiement/glitch.

### Cheby (Chebyshev) <Badge text="Nouveau" type="info" />
Paramètres : Ordre Cheby, Inclin Cheby, Déform Cheby. Distorsion polynomiale, propre à complexe.
