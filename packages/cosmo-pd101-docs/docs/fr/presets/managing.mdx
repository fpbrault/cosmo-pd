# Gestion des presets

<img src="../../assets/WebAppLibrary.jpeg" />

## Où sont stockés les presets

IndexedDB (application web) ou répertoire local des presets (bureau/plugin). Exportables au format JSON.

## Chargement d'un preset

1. Cliquez sur l'icône preset -> ouvrez la bibliothèque.
2. Parcourez/recherchez par nom.
3. Cliquez sur un preset pour le charger.

## Sauvegarde d'un preset

1. Ajustez les contrôles. 2. Cliquez sur "Sauvegarder le preset". 3. Entrez un nom. 4. Optionnellement définissez l'auteur et les tags.

## Format de fichier des presets

Schéma JSON versionné (v1) avec paramètres pour lineSelect, modMode, octave, volume, polyMode, portamento, line1, line2, modMatrix, fxSlots.

## Importation/Exportation

Exportez au format `.json`, importez des fichiers `.json`. Portabilité sur toutes les plateformes (Web, Bureau, Plugin).

## Importation SysEx Casio CZ-101

Voir [Import / Export SysEx](/presets/sysex).

## Organisation des presets

:::tip
Utilisez la recherche, les catégories, les tags et les favoris (étoile) pour garder votre bibliothèque de presets organisée à mesure qu'elle grandit.
:::
