# Pour commencer

Bienvenue sur le **Cosmo PD-101** -- un synthétiseur à distorsion de phase inspiré du légendaire Casio CZ-101, enrichi de capacités de synthèse modernes et disponible en application web et plugin DAW.

## Ce dont vous avez besoin

- Un ordinateur (Windows, macOS ou Linux)
- Un navigateur web (Chrome, Firefox, Edge -- dernières versions)
- Un clavier ou contrôleur MIDI (optionnel mais recommandé)

## Premier son

<Steps>

### Ouvrez l'application Web

Naviguez vers [cosmo.purraudio.dev](https://cosmo.purraudio.dev) dans votre navigateur. Aucune installation requise.

### Jouez une note

Appuyez sur les touches de votre clavier d'ordinateur (**A S D F G H J K** pour une gamme de Do majeur) ou connectez un contrôleur MIDI.

### Ajustez à votre goût

Parcourez la bibliothèque de presets et sélectionnez un son qui vous plaît. Modifiez les paramètres individuels pour comprendre leur effet.

</Steps>

:::tip
Commencez par explorer les presets d'usine avant de plonger dans la synthèse.
:::

## L'interface en un coup d'œil

Utilisez le sélecteur **Simple / Advanced** en haut du synthétiseur. Les nouvelles sessions s’ouvrent en mode **Simple** ; votre choix est mémorisé. Les deux modes modifient le même son : changer de mode conserve le patch actuel.

### Simple : jouer et façonner un son

Quatre **Macros** restent accessibles à côté de trois sections. Sélectionnez une section réduite pour la développer :

| Section | Utilisation |
|---------|-------------|
| **Sound** | Choisissez les algorithmes de chaque ligne, ajustez DCA (niveau), DCW (forme d’onde), octave et mélange, puis le routage, la modulation ring/noise, le désaccord, le mode mono et le portamento. Le mélange apparaît lorsque l’algorithme B est activé. |
| **Envelope** | Sélectionnez la ligne 1 ou 2. Choisissez des presets pour DCO (hauteur), DCW (forme d’onde) et DCA (amplitude), ou cliquez sur un graphique pour ouvrir son éditeur. |
| **Effects** | Ajoutez des effets aux six emplacements et ouvrez un effet pour modifier ses réglages. |

La commande d’octave de la ligne 1 transpose les deux lignes. Celle de la ligne 2 définit un décalage par rapport à cette octave de base.

### Advanced : modifier le patch complet

Passez en mode **Advanced** pour accéder aux éditeurs complets, à la matrice de modulation et aux réglages globaux de tempo et d’allocation des voix. L’interface est organisée en sections :

| Section | Ce qu'elle contrôle |
|---------|-------------------|
| **Lignes de phase** | Deux lignes d'oscillateurs -- chacune avec son algorithme, enveloppe et réglages de hauteur |
| **Éditeur d'enveloppes** | Enveloppes à paliers de 8 étapes pour DCO, DCW et DCA, par ligne |
| **Matrice de modulation** | Route 11 sources de modulation vers la plupart des paramètres |
| **Chaîne FX** | 6 emplacements d'effets en série avec 17 types d'effets |
| **Commandes globales** | Polyphonie, portamento, volume, plage de pitch bend, sensibilité à la vélocité |

## Connexion d'un contrôleur MIDI

1. Ouvrez les **paramètres MIDI** du navigateur.
2. Autorisez l'accès à votre périphérique MIDI lorsque demandé.
3. Sélectionnez votre contrôleur dans le menu déroulant d'entrée MIDI.
4. Jouez.

## Mini-clavier

Un clavier à l'écran est disponible lorsqu'aucun contrôleur MIDI physique n'est connecté.

- **Cliquez ou glissez** sur les touches pour jouer.
- Les boutons de **changement d'octave** déplacent la plage vers le haut ou le bas.
- En mode **Velocity**, appuyez près du haut d’une touche pour une note plus forte, ou près du bas pour une note plus douce.
- En mode **Aftertouch**, glissez vers le haut après avoir appuyé pour ajouter de la pression. Choisissez le mode dans les réglages du clavier.
- Fonctionne à la fois dans l'application web et dans l'interface du plugin.

## Raccourcis clavier

| Touche | Action |
|--------|--------|
| A S D F G H J K | Jouer des notes (gamme Do majeur : C4-C5) |
| Espace | Activer/désactiver le sustain |
