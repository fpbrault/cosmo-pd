# Contributing to Cosmo PD

Thank you for your interest in contributing to Cosmo PD! We welcome community bug fixes, documentation improvements, and feature enhancements. Please read this entire document—including our **Contributor License Agreement (CLA)** at the bottom—before submitting a Pull Request.

---

## 1. Contribution Workflow

1. **Check Issues:** Look for existing issues or open a new one to discuss major architectural changes before writing code.
2. **Fork & Branch:** Create a feature branch off of `main` (e.g., `feature/optimize-env-generator`).
3. **Keep PRs Focused:** Keep your changes targeted. Ensure your styling matches our configuration (`biome.json` for JS/TS, `cargo fmt` for Rust).
4. **Submit & Sign:** Open your Pull Request against the upstream `main` branch.

> **⚠️ Important:** By opening a Pull Request, you explicitly agree to the Contributor License Agreement below. Pull Requests cannot be merged without this confirmation.
